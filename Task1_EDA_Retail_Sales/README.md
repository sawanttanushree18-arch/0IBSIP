# Task 1: EDA on Retail Sales Data

## Internship
AICTE Oasis Infobyte Internship — Data Analytics

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset using Python. The aim is to understand sales patterns, customer demographics, and product category performance through data analysis and visualisations.

## Objectives
- Inspect the dataset structure and data types.
- Check for missing values and calculate descriptive statistics.
- Analyse monthly and quarterly sales trends.
- Explore customer age groups and gender distribution.
- Identify the best-performing product categories.
- Study relationships between numerical variables using a correlation heatmap.
- Present findings and practical business recommendations.

## Dataset Information
The dataset contains 1,000 rows and 9 columns.

Columns include:
- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

The dataset contains no missing values. It includes product categories rather than individual product names, so product-level analysis will be limited to the information available.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Planned Analysis
1. Dataset inspection and data cleaning checks.
2. Descriptive statistics for numerical columns.
3. Monthly and quarterly sales trend analysis.
4. Customer age-group and gender analysis.
5. Product category and revenue analysis.
6. Correlation heatmap.
7. Additional visualisation to discover useful patterns.
8. Conclusion with actionable business recommendations.
